# Sequence

Generate when source material provides ordered calls, messages, async events, or agent orchestration. Prefer PlantUML sequence for complex interactions and Mermaid for simple interactions. Use light visual enhancement after the semantic gate passes.

Use `sequence-lifelines`. Keep participant order stable and messages strictly top-to-bottom. Express grouping, activation, and async behavior without moving messages out of order. Split scenarios when the participant or message budget is exceeded.
