# Deployment

Generate when source material names environments, containers, servers, network boundaries, or infrastructure. Prefer PlantUML deployment or Graphviz and strong visual enhancement.

Choose `deployment-zones` for nested environments, zones, hosts, and containers; use `layered-system` only when runtime tiers matter more than physical placement. Draw containment and trust boundaries before connections. Route cross-zone links through boundary edges and split application architecture from physical deployment when both become dense.
