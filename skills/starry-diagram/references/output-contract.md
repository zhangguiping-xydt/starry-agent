# Output Contract

## Pack layout

```text
pack/
  diagram_manifest.yaml
  manifest_report.json
  diagram_pack_report.json
  <diagram-id>/
```

## Per diagram layout

```text
<diagram-id>/
  diagram_spec.md
  diagram_lock.yaml
  source.*
  semantic.svg or render_unavailable
  visual.svg or visual_failed
  preview.png
  preview_review.yaml
  embed.md
  check_report.json
```

`lock_report.json`, `semantic_report.json`, `visual_report.json`, `preview_report.json`, `preview_review_report.json`, and `check_report.json` must be generated by `build_check_report.py`. Do not hand-author pass statuses. The reports record source/semantic/visual/preview hashes, layout-plan and complexity validation, geometry coverage, crossings, non-endpoint node intrusions, long edges, delivery-scale typography, text containment, collisions, contrast, semantic drift, preview dimensions, the review-to-preview-and-visual hash binding, and whether the visual geometry changed.

## Embed block

`embed.md` embeds `visual.svg` first and links to `preview.png` as the consumer-size review artifact. If `visual.svg` is missing, use `semantic.svg`. If both are unavailable, link to `render_unavailable` and `check_report.json` so the user sees the exact failure reason.

The pack-level report must fail when the manifest disagrees with a generated diagram lock or any generated diagram has a missing, invalid, or failed check report.
