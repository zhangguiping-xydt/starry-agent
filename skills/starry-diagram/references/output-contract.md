# Output Contract

## Pack layout

```text
pack/
  diagram_manifest.yaml
  manifest_report.json
  diagram_pack_report.json
  <diagram-id>/
```

## Per diagram layout

```text
<diagram-id>/
  diagram_spec.md
  diagram_lock.yaml
  source.*
  semantic.svg or render_unavailable
  visual.svg or visual_failed
  preview.png
  preview_review.yaml
  delivery.png                 # required when raster_delivery is declared
  delivery_render_report.json  # required when raster_delivery is declared
  delivery_report.json         # generated by build_check_report.py
  embed.md
  check_report.json
```

`lock_report.json`, `semantic_report.json`, `visual_report.json`, `preview_report.json`, `preview_review_report.json`, optional `delivery_report.json`, and `check_report.json` must be generated by `build_check_report.py`. Do not hand-author pass statuses. The reports record source/semantic/visual/preview/delivery hashes, viewpoint and notation validation, layout-plan and complexity validation, geometry coverage, crossings, non-endpoint node intrusions, long edges, delivery-scale typography, text containment, collisions, contrast, semantic drift, preview dimensions, raster pixel density, the review-to-preview-and-visual hash binding, and whether the visual geometry changed.

## Embed block

`embed.md` embeds `visual.svg` first and links to `preview.png` as the consumer-size review artifact. When `raster_delivery` is declared, it also links to `delivery.png` as the high-density publication artifact. If `visual.svg` is missing, use `semantic.svg`. If both are unavailable, link to `render_unavailable` and `check_report.json` so the user sees the exact failure reason.

The pack-level report exposes type, viewpoint, layout, notation, and repeated-signature counts. It must fail when contract v3 diversity rules fail, the manifest disagrees with a generated diagram lock, or any generated diagram has a missing, invalid, or failed check report.
